60fps Patch for Mario & Luigi: Bowser's Inside Story + Bowser Jr.'s Journey (3DS)
==================================================================================

Two patches are provided - use the one matching your game version:

  60fps.ips              - Base game (v1.0, no update)
  60fps_update_v1.2.ips  - Updated game (v1.1 or v1.2)

Works on all regions (USA, EUR, etc).

USING THE WRONG PATCH WILL CRASH THE GAME. If the game crashes on
startup, try the other patch.


Quick Install (Windows)
-----------------------
Run install_60fps.bat - it auto-detects your version and installs.


Manual Install
--------------
1. Rename the correct .ips file to "code.ips"
2. Place it in your emulator's mod folder:

   Azahar:  %APPDATA%\azahar-emu\load\mods\00040000001D1400\exefs\code.ips
   Lime3DS: %APPDATA%\Lime3DS\load\mods\00040000001D1400\exefs\code.ips
   Citra:   %APPDATA%\Citra\load\mods\00040000001D1400\exefs\code.ips

3. Launch the game. FPS should jump from ~30 to ~60.


How to tell which version you have
-----------------------------------
- If you never installed an update: v1.0 -> use 60fps.ips
- If you installed the update (from eShop or CIA): v1.1/v1.2 -> use 60fps_update_v1.2.ips
- If unsure, try 60fps_update_v1.2.ips first (most people have the update)
- If the game crashes, switch to the other one
